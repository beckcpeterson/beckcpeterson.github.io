# Beck Peterson Portfolio

This folder contains the complete website for `https://beckcpeterson.github.io`.

## Files you will see

- `index.html` — all of the website wording and sections
- `styles.css` — colors, spacing, fonts, and mobile layout
- `Beck-Peterson-Resume.pdf` — the downloadable resume
- `og.png` — the preview image shown when the website is shared
- `favicon.svg` — the small browser-tab icon
- `.nojekyll` — tells GitHub Pages to publish the files exactly as provided

## Easiest way to edit later

1. Open your `beckcpeterson.github.io` repository on GitHub.
2. Click `index.html`.
3. Click the pencil icon labeled **Edit this file**.
4. Change only the wording you want to update.
5. Click **Commit changes** and then **Commit changes** again.
6. Wait about one minute and refresh your website.

The comments inside `index.html` label the Hero, Selected Work, Experience, About, and Contact sections. If you are unsure about an edit, make a copy of the existing section before changing it or ask for help.

## Replace the resume later

Upload the new PDF using the exact filename `Beck-Peterson-Resume.pdf`, choose **Replace**, and commit the change. The resume button will keep working automatically.
